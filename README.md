# WhaleFloat

> **内容已迁至 fork：[tigriyang/DeepSeek-Balance-Whale-Widget](https://github.com/tigriyang/DeepSeek-Balance-Whale-Widget)**

那个仓库是 [MeteorNOX/DeepSeek-Balance-Whale-Widget](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget)
的 fork —— 同一只盯着余额的小鲸鱼，从 DSH 网页插件（JavaScript）
移植成了独立的 macOS 程序（Swift + AppKit）。

## 两个版本

| | 上游原版 | 移植版 |
|---|---|---|
| 形态 | DSH 网页插件 | 独立 macOS 程序 |
| 语言 | JavaScript | Swift + AppKit |
| 运行位置 | 浏览器页面内 | 桌面浮窗 |
| 仓库 | [MeteorNOX/...](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget) | [tigriyang/...](https://github.com/tigriyang/DeepSeek-Balance-Whale-Widget) |

角色立绘、音效与交互设计都源自上游，这次移植只做实现语言的转换。

## 这个仓库为什么空了

最初把它建成独立仓库，后来意识到这本质上是对上游的一次**移植** ——
idea 和素材都来自上游，用 fork 才能让这份继承关系在 GitHub 上始终可见。
于是迁去了 fork，这里只留一个指路牌。
